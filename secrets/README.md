# secrets/ — 本地敏感信息（不入库）

本目录存放**本地敏感信息**：远程主机连接凭据、token、本地配置等。
**一律不提交、不入库**——`.gitignore` 已忽略 `secrets/` 下所有内容。

本 README 是唯一例外（反向忽略保留入库），作用：`git clone` 后自动创建本目录，
让 agent / 协作者知道"敏感信息放这里"。

## 放什么

- 远程主机连接信息（VPS / VM / 云主机：IP、端口、用户、密码、SSH key 路径；
  真实主机名/系统只写在本地 `remote-hosts.md`，不在公开文档出现）
- API token、密钥（如发布用 PAT）
- 本地专属配置（不入公开文档的环境覆盖）

## 规则

- `secrets/` 下新文件**不会**被 git 跟踪，无需担心误提交
- 不要在 README.md / AGENTS.md / 公开文档里写这些信息
- 敏感信息一律经本目录或本地配置读取，禁止写进对话/commit/issue/PR
